# چت با Gemma3-1B (Ollama + Streamlit)

یک رابط چت ساده و فارسی‌محور با مدل **gemma3:1b** از طریق Ollama و رابط کاربری Streamlit.

## ویژگی‌ها

- چت تعاملی با مدل `gemma3:1b`
- تولید پاسخ به صورت **استریم** (کلمه به کلمه)
- قابلیت **توقف تولید پاسخ** در حین تولید
- ذخیره کامل مکالمه در فایل متنی
- خلاصه‌سازی کل چت با خود مدل و ذخیره خلاصه
- رابط کاربری فارسی و سایدبار کنترل‌ها

## پیش‌نیازها

1. **Python 3.10+**
2. **Ollama** نصب و در حال اجرا باشد:
   ```bash
   # نصب Ollama (در صورت نیاز)
   # سپس مدل را دانلود کنید:
   ollama pull gemma3:1b
   ```
3. کتابخانه‌های پایتون:
   ```bash
   pip install streamlit ollama requests
   ```

## ساختار پروژه

```
.
├── app.py          # برنامه اصلی Streamlit (چت + ذخیره + خلاصه)
├── utils.py        # تابع کمکی برای فراخوانی API Ollama
└── README.md
```

پوشه‌های زیر به‌صورت خودکار ساخته می‌شوند:
- `chats/`      → فایل‌های کامل مکالمه
- `summaries/`  → فایل‌های خلاصه

## نحوه اجرا

```bash
streamlit run app.py
```

سپس مرورگر روی آدرس `http://localhost:8501` باز می‌شود.

## راهنمای استفاده

1. پیام خود را در کادر پایین بنویسید و Enter بزنید.
2. در حین تولید پاسخ می‌توانید از سایدبار روی **⏹️ توقف تولید پاسخ** کلیک کنید.
3. از سایدبار می‌توانید:
   - تاریخچه را پاک کنید
   - کل چت را در فایل ذخیره کنید
   - خلاصه کل مکالمه را بگیرید و ذخیره کنید

## نکات مهم / باگ‌های فعلی کد

در فایل `app.py` چند مورد نیاز به اصلاح دارد:

| مورد | توضیح | اصلاح پیشنهادی |
|------|--------|----------------|
| `from pathlib import path` | باید `Path` باشد | `from pathlib import Path` |
| `SUMMARY_DIR = ('summaries')` | فعلاً یک `tuple` است | `SUMMARY_DIR = Path('summaries')` |
| `SUMMARY_PROMPT` | تعریف نشده ولی استفاده شده | باید یک پرامپت خلاصه‌سازی تعریف شود |
| `CHAT_DIR = path ('chats')` | فاصله و نام اشتباه | `CHAT_DIR = Path('chats')` |

نسخه اصلاح‌شده‌ی ابتدای فایل می‌تواند این‌گونه باشد:

```python
from pathlib import Path

CHAT_DIR = Path('chats')
SUMMARY_DIR = Path('summaries')
CHAT_DIR.mkdir(exist_ok=True)
SUMMARY_DIR.mkdir(exist_ok=True)

MODEL_NAME = 'gemma3:1b'

SUMMARY_PROMPT = """مکالمه زیر را به صورت مختصر و مفید خلاصه کن.
نکات اصلی، سوالات کاربر و پاسخ‌های مهم را پوشش بده:

{chat_text}
"""
```
